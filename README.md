# Problem #7: Employee Productivity vs. Workload Intelligence

## Overview
An operational and organizational analytics system that identifies the productivity inflection point, empirically demonstrating how excessive overtime hours trigger steep defect rework rates and bottleneck throughput.

### Features
- **Diminishing Returns Modeling**: Illustrates productivity collapse when weekly hours climb past sustainable thresholds.
- **Defect & Rework Correlation**: Links fatigue to high defect review loops and project delay penalties.
- **Team-Level Strain Profiler**: Identifies business units operating in the high-exhaustion burnout zone.
- **Actionable Manager Interventions**: Provides workload rebalancing and sprint gating recommendations.

python main.py
